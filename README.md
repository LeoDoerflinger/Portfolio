## 💻 Ejecución Local

1. Abrí la terminal en la carpeta `Portfolio`:
   ```bash
   cd Portfolio
   ```
2. Ejecutá un servidor local simple:
   ```bash
   python -m http.server 8080
   ```
3. Ingresá en: `http://localhost:8080`
